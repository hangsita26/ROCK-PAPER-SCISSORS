**ROCK PAPER SCISSORS**

1. Project Title:

Rock Paper Scissors

2. Overview of the Project:

Rock Paper Scissors is a simple command-line game developed using Python.

The project allows a user to play against the computer. The user selects Rock, Paper, or Scissors, and the computer randomly selects one of the three choices. The program compares both choices and displays whether the result is a win, loss, or draw.

The project is divided into different Python files to organize the input handling, game logic, score management, display, and testing.

3. Features:

The main features of the project are:

1. Allows the user to select Rock, Paper, or Scissors.
2. Generates the computer's choice randomly.
3. Compares the user's choice with the computer's choice.
4. Determines whether the user wins, loses, or draws.
5. Displays the player's choice and computer's choice.
6. Maintains the player score.
7. Maintains the computer score.
8. Displays the player and computer scores.
9. Checks whether the user's input is a valid choice.
10. Displays an invalid choice message for unsupported input.
11. Separates the program into different Python modules.
12. Includes a separate test file for testing the game logic.


 4. Technologies / Tools Used:

* Python 3 - Used to develop the game.
* Python random module - Used to randomly select the computer's choice.
* Visual Studio Code - Used to write, edit, and run the Python program.
* Python functions and conditional statements - Used to implement the game logic.
* VS Code Terminal - Used to run the project and test program.

6. Program Files:

* main.py - Controls the overall execution of the game.
* game_config.py - Stores the game choices.
* input_handler.py - Handles the user's input.
* game_logic.py - Determines the result of the game.
* score_manager.py - Manages the player and computer scores.
* display.py - Displays the game title, choices, results, and scores.
* test_game.py - Tests important game conditions.
* README.md - Contains project documentation.
* statement.md - Contains the problem statement, scope, target users, and high-level features.

7. Steps to Install & Run the Project:

Install Python 3 or a compatible version on your computer.
Open the Project folder in vs code.
Open the terminal.
Run: python main.py
