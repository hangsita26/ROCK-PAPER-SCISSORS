**ROCK PAPER SCISSORS**


1. Problem Statement:

Rock Paper Scissors is a simple command-line game developed using Python. The project allows a user to play against the computer by selecting Rock, Paper, or Scissors.

The computer randomly selects one of the three choices. The program compares the player's choice with the computer's choice and displays whether the player wins, the computer wins, or the game is a draw.

The project is designed to demonstrate basic Python programming concepts such as user input, conditional statements, functions, modules, random selection, score management, and basic testing.

2. Scope of the Project:

The scope of this project includes-

* A command-line based Rock Paper Scissors game.
* Player selection of Rock, Paper, or Scissors.
* Random selection by the computer.
* Comparison of player and computer choices.
* Display of the game result.
* Display of player and computer scores.
* Handling of invalid player input.
* Separate Python modules for different parts of the program.
* A separate test file for checking important game outcomes.

The current version does not include a graphical user interface, online multiplayer, database storage, or network features.


3. Target Users:

The target users of this project are-

* Students learning Python programming.
* Beginners practicing Python concepts.
* Users who want to play a simple command-line game.
* Students who want to understand modular programming and basic testing.

 4. High Level Features:

The main features of the project are-

1. Displays the Rock Paper Scissors game menu.
2. Accepts the player's choice.
3. Validates the player's input.
4. Randomly generates the computer's choice.
5. Compares the player and computer choices.
6. Determines the winner or draw.
7. Updates the player and computer scores.
8. Displays the result and scores.
9. Uses separate Python modules for different responsibilities.
10. Includes a 'test_game.py' file for testing game outcomes.
